# Archive — non-operational material

Everything below `archive/` is retained only as historical evidence. Files here
are excluded from the supported local runtime and must not be executed, imported
or copied back into `scripts/` without a new review and an explicit policy
change.

- `cloud-local/` preserves cloud, rental, remote-sync and 2.5B/5B-era material;
- `legacy-scratch/` preserves one-off launchers, patches and cleanup helpers;
- `historical-docs/` preserves superseded reports and roadmaps;
- `historical-evaluations/` preserves earlier evaluation outputs.

The authoritative executable classification is
`audit/policy/operational-surface.json`.
